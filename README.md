This is an example of a qualitative data analysis. 
In the code, I configured a Python environment in R where I ran an aspect-based sentiment analysis model (Roberts) from HuggingFace. 
To correctly identify the aspects, I needed to install the spaCy English model.
I also used the BART model to predict sentiment toward each extracted attribute.
The main outputs were:
- automatically extracted attributes and their sentiment predictions
- similar aspects organized into clusters
- sentiment word cloud and a comparison bar chart
